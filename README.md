# 누리링크 (NURI LINK)

유아교육기관 **5종 서류(연간계획안 · 주간계획안 · 알림장 · 관찰일지 · 상담일지) 통합 연동 웹앱**입니다.
만 5세 '햇살반' 샘플 데이터가 들어 있어 접속하자마자 시연할 수 있고, 모든 기록은 브라우저(localStorage)에 저장됩니다.

## 접속 주소

- 사이트: https://osuum203-ai.github.io/kinder-doc-sync/
- 저장소: https://github.com/osuum203-ai/kinder-doc-sync

## 서류가 이어지는 방식

| 서류 | 하는 일 | 쓰는 Key | 만드는 데이터 |
| --- | --- | --- | --- |
| ① 연간계획안 | 월별 대주제·주차 설계 | — | 월·주차, 주제, 목표 |
| ② 주간계획안 | 연간계획안의 주제·목표 자동 연결 | 월·주차 | 요일별 활동, 가정 연계 안내 |
| ③ 알림장 | 활동을 학부모 문장으로 변환 | 월·주차 + 원아 ID | 인사말, 주간 안내, 원아별 전달사항 |
| ④ 관찰일지 | 원아별 관찰 기록 | 원아 ID + 영역 태그 | 관찰 내용, 누리과정 영역 |
| ⑤ 상담일지 | 관찰일지·알림장 자동 집계 | 원아 ID | 영역별 발달 요약, 상담 포인트 초안 |

- **연간계획안 → 주간계획안**: 주차 카드를 누르면 그 주의 대주제·목표가 주간계획안 상단에 자동으로 표시됩니다.
- **주간계획안 → 알림장**: `알림장으로 연동하기`를 누르면 요일별 활동과 가정 연계 안내가 학부모 눈높이의 구어체 문장으로 바뀌어 알림장 초안이 됩니다.
- **관찰일지 → 상담일지**: 원아를 고르면 누적 관찰일지와 알림장 기록이 누리과정 5개 영역별로 집계되어 발달 요약과 상담 포인트 초안이 생성됩니다.
- **데이터 매핑 구조** 화면에서 세 Key와 서류별 사용 관계를 한눈에 볼 수 있습니다.

## 기능

- 통합 대시보드: 5단계 연동 흐름도, 이번 주 주제·활동, 작성 건수, 최근 기록
- 연간계획안: 3월~12월 월별 대주제·월 목표·주차별 주제, 누리과정 5개 영역
- 주간계획안: 요일별 활동 추가·수정, 영역 균형 보기, 가정 연계 안내 편집
- 알림장: 자동 변환 초안, 원아별 기분·식사·낮잠·코멘트, 학부모 스마트폰 미리보기
- 관찰일지: 원아 선택 + 이번 주 활동 연결 + 영역 태그 + 관찰 내용 저장
- 상담일지: 영역별 발달 요약, 상담 포인트 초안, 교사 소견 저장
- 상단/사이드바 `샘플 데이터 초기화`로 언제든 처음 상태로 복원

## 기술

- 정적 사이트(HTML/CSS/Vanilla JS), 빌드 도구 없음 → GitHub Pages로 배포
- 데이터: 브라우저 `localStorage` (`nurilink.v1`)
